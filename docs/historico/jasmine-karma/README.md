# Evidencia histórica de Jasmine y Karma

Estos registros se conservaron para acreditar los escenarios anteriores a la migración. No son resultados de Vitest ni deben usarse como cobertura vigente. El registro de Chrome tenía 120 casos y el de Edge 101; corresponden a momentos distintos del proyecto.

La evidencia vigente está en `docs/RESULTADOS.md`, `docs/COBERTURA.md` y los JSON de Vitest. La lista `docs/casos-originales.json` permite verificar que ningún caso original desapareció durante la migración.
